# AI 姿势参考库 · 中文汉化版

> 288 组人体姿势、1439 张多角度参考图的**纯静态**画廊：零依赖、零构建，可本地离线运行，支持按体系、分类、视角筛选与一键下载原图。

**在线体验：** [https://atom-kkk.github.io/AI-Pose-Resource-Library/](https://atom-kkk.github.io/AI-Pose-Resource-Library/) · **原始图库：** [ai-pose-gallery.pages.dev](https://ai-pose-gallery.pages.dev/)（POSE Atlas） · **原作者：** ギア

---

## 这是什么

原始图库是一套面向 AI 绘画的人体姿势参考素材（无五官的灰色素体线稿，不含人物面部与真实人物），元数据为日文，单页静态 HTML。本项目在它的基础上做成一个**可以长期自己用下去**的工具：

1. **素材完全本地化** —— 1439 张缩略图（共约 25 MB）全部落地到 `thumbs/`，断网、无 CDN 也能正常浏览。
2. **中文汉化** —— 体系、分类、姿势名、角度全部译为中文，搜索与筛选更顺手。
3. **多维度筛选** —— 按体系（全身单人·标准系 / 性感系 / 上半身 / 双人）、动作分类（站姿 / 坐姿 / 趴卧等 26 类）、视角（正面 / 侧面 / 斜侧 / 俯视 / 仰视）交叉筛选。
4. **多角度对比** —— 同一姿势支持 5 个视角切换，便于保持生成图中的姿态一致。
5. **零门槛运行** —— 只有一个 `index.html`（数据内联），双击就能用；也能扔到任意静态托管上。

## 功能

### 浏览

- 按体系、分类、视角交叉筛选，计数按实际条目实时统计
- 关键词搜索（姿势名、编号、ID、分类）
- 按姿势分组 / 逐张浏览两种视图切换
- 卡片悬停切换角度预览，点击进入大图灯箱
- `← / →` 切换角度，`↑ / ↓` 切换姿势，`Esc` 关闭；手机可左右滑动

### 下载

- 大图灯箱内可下载 900 × 1200 原尺寸 PNG

## 本地使用

**方式一：直接双击**

打开 `index.html` 即可，无需服务器、无需联网。

**方式二：本地静态服务器（推荐）**

```bash
cd AI-Pose-Resource-Library
python3 -m http.server 8080
# http://localhost:8080
```

## 部署

纯静态文件，扔哪都能跑：

| 平台 | 做法 |
|------|------|
| 任意静态托管 | 上传全部文件，入口 `index.html` |
| GitHub Pages | Settings → Pages → 分支 `main` / 根目录 |
| Cloudflare Pages / Vercel / Netlify | 构建命令留空，输出目录 `/` |
| 内网 / NAS | 放进 Web 目录即可 |

## 原图（PNG）说明

仓库主体只提交缩略图（`thumbs/`，约 25 MB），克隆快、Pages 不会超限。1439 张 900×1200 无损原图（约 640 MB）保存在本地 `img/`，走 `.gitignore` 不入库。

如需补齐原图，运行随附的下载脚本（断点续传 + 并发）：

```bash
python3 fetch_assets.py
```
